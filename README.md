# FORUS WooCommerce Payment Gateway\n\nAccept mobile money, instant payments, and USSD at any WooCommerce store.\n\n## Requirements\n\n- WordPress 6.0+\n- WooCommerce 8.0+\n- PHP 8.1+\n- FORUS API key (free at [developer.forus.digital](https://developer.forus.digital))\n\n## Installation\n\n1. Download the latest release zip\n2. WordPress Admin → Plugins → Add New → Upload Plugin\n3. Activate → WooCommerce → Settings → Payments → FORUS\n4. Enter your FORUS API key\n\n## Documentation\n\nFull documentation: [developer.forus.digital/plugins/woocommerce](https://developer.forus.digital/plugins/woocommerce)\n\n## Supported payment methods\n\n- Mobile money (M-Pesa, MTN MoMo, Airtel, VietQR, MoMo Vietnam)\n- Instant bank transfer (EFT, PayShap)\n- Card (Visa, Mastercard, Amex)\n- QR Code\n- USSD\n\n## Supported countries\n\nSouth Africa, Nigeria, Kenya, Ghana, Uganda, Tanzania, Vietnam, Sri Lanka, Hungary, India, Brazil, and 20+ more.\n\n## License\n\nGPL-2.0-or-later
